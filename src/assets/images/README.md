# Images Folder

## Meeting Room Image

Place your meeting room image here with the filename: `meeting-room.jpg`

### Image Requirements:
- **Filename:** `meeting-room.jpg`
- **Format:** JPG, PNG, or WebP
- **Recommended size:** 400x400px or higher for HD quality
- **Description:** Image should show people around a rustic wooden table in a meeting setting

### Image Description:
The image should match this description:
- People seated around a dark brown wooden table
- One person writing in a yellow notebook
- Natural lighting from the side
- Collaborative meeting atmosphere
- Close-up view focusing on hands and table

### How to Add:
1. Download or save your meeting room image
2. Place it in this folder: `src/assets/images/`
3. Name it exactly: `meeting-room.jpg`
4. The component will automatically import and use it
